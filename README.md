# Diplomatura aplicada: SAIJ + Consorcio

Dos pistas, el mismo método de la mentoría FaMAF 2026 (unidad → curación → cluster/clase → búsqueda). **RAG es un paso extra después del P3-equivalente**, no el día 1.

Sitio: GitHub Pages (`docs/`).

## Pistas

| Pista | Datos | Estado |
|---|---|---|
| **SAIJ** | Jurisprudencia (muestra oficial + censo documentado) | P1–P3 entregables |
| **Consorcio** | Corpus legal público (normas/artículos), no actas privadas | Empieza en P1-equivalente |

Números de lluvia / GEE **no** entran: son otro producto (Lluvia v2).

## Qué no va en este repo

- JSONL de 2,5 GB ni `work-sample` de 50k
- Actas, padrón, documentos privados del consorcio
- Notebooks del grupo de la mentoría

## Uso académico

No es asesoramiento jurídico. El buscador SAIJ no es RAG.
