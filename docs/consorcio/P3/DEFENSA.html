Teoría en este caso

El split por documento, que era lo correcto contra la fuga, desnuda el desbalance: casi todo el test es “ley larga”. Publicar 0,88 es hacer trampa con accuracy. Macro 0,16 dice: no distinguís decreto de ley cuando casi no hay decretos en test.

La Y grosera de 3 clases es el equivalente de D5 SAIJ: no es el fenómeno jurídico fino, es el tipo de registro. Ahí el texto alcanza (secundario no habla como articulado). No se usó el campo tipo como feature. No se re-partió el split después de ver el F1.
