# Mentoria Jurisprudencia

Carpeta preparada para materiales FaMAF 2026.

## Estructura

- `clases/`: material oficial descargado o descargable. Esta carpeta debería quedar ignorada en git.
- `manifest.md` / `manifest.json`: trazabilidad curso → FaMAF → archivo local o acción manual.

- `materiales-oficiales/`: links/archivos oficiales de la mentoría.
- `practicos/`: consignas y entregas propias.
- `notebooks/`: experimentos.
- `data-notes/`: notas de datos.
- `rag/`: componentes de recuperación/búsqueda.
